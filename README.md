משימה: הקמת מערכת ניהול תלמידים עבור מורים, עם ניהול מטלות
תיאור:
המטרה של המטלה היא לפתח חלק ממערכת ניהול תלמידים בממשק אינטרנטי.
דרישות:
הקמת עמוד בית לאתר שכולל:
אימות משתמש: יישום יכולות אימות משתמש, המאפשר למשתמש מסוג 'מורה' להתחבר באמצעות פרטי הזיהוי שלהם (שם ותעודת זהות).
בתוך פרופיל המשתמש - יצירת פרופיל ל'תלמיד' שמאפשר עדכון פרטים אישיים (שם, כיתה, טלפון)
ממשק משתמש: עיצוב ממשק משתמש ידידותי המאפשר ניווט קל וניהול יעיל של מידע תלמידים ומטלות. יש לשקול שימוש במסגרות או ספריות עיצוב CSS מתאימות כדי לשדרג את הממשק המשתמש.
מסירת התוצרים:
קוד מקור: המפתח יספק את הקוד המלא של מערכת ניהול התלמידים, כולל הלוגיקה האחורית ורכיבי הפרונט-אנד.
